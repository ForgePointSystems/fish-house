# Glossary

Domain terms, in the facility's own words. Fill this in as we learn them — using
the crew's vocabulary in the schema and the UI is most of what makes software
feel like it belongs in a workplace.

Where our term and theirs differ, theirs wins.

## Placeholders — confirm all of these

**Lot** — a quantity of fish received together and tracked as a unit, carrying a
lot number used for traceability. Confirm what defines a lot here: a delivery, a
vessel trip, a species within a delivery?

**Pull** — removing fish from inventory for a specific order. The core
transaction of the app.

**Order** — a restaurant's request for product. Confirm whether one order can
span multiple species and multiple pulls.

**Ticket / label** — the printed output of a pull, telling the processing room
which order the fish in front of them belongs to.

**Yield** — product out over product in, across a processing step. Confirm
whether this is tracked today and at what granularity.
